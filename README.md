# Todo CLI

Une application de gestion de tâches en ligne de commande écrite en Dart.

## Prérequis

- Dart SDK installé
- Un terminal disponible

## Lancer l'application

```bash
dart run bin/main.dart
```

## Exécuter les tests

```bash
dart test
```

## Fonctionnalités

- Ajouter une tâche
- Lister les tâches
- Marquer une tâche comme terminée
- Supprimer une tâche
- Gérer la priorité et la date limite
